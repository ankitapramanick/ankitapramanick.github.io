# Ankita Pramanick Portfolio

This is a portable static copy of the portfolio. It can be hosted on GitHub Pages or another static-website host without ChatGPT in the public URL.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `ankita-portfolio`.
2. Upload every file and folder from this package to the repository root.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a URL similar to `https://YOUR-USERNAME.github.io/ankita-portfolio/`.

For a cleaner address such as `ankitapramanick.com`, purchase a domain and connect it in the hosting settings.

## Update the resume later

1. Export the new resume as a PDF.
2. Rename it exactly to `Ankita_Pramanick_Resume.pdf`.
3. Open the `assets` folder in the repository.
4. Replace the existing PDF with the new PDF and commit the change.
5. Wait a few minutes for the website to redeploy.

The portfolio address and resume buttons will remain unchanged because the PDF filename stays the same.

## Update portfolio text

- Open `index.html` in GitHub's editor.
- Make the required text changes and commit them.
- Styling is stored in `styles.css`, and download/mobile-menu behavior is stored in `script.js`.
